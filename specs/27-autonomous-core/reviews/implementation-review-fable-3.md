## Verified, no finding

- **Agent authority never exceeds the caller.** Agent steps and `run-checks` run under `bwrap` with `/` read-only, the worktree writable minus `ballast.toml`, `.ballast/`, `.specify/`, `.venv/` and `.git/` ([autonomy.py:1301-1327](../../../tools/spec_workflow/autonomy.py)); tmpfs over `/tmp`, `/run`, `/var/run`, `$XDG_RUNTIME_DIR`; pid and ipc unshared, new session. The decision log, run record and mode live in operator state; recorders validate drafts and the record is a re-rendered projection (`autonomous_preamble`, [artifacts.py:676-690](../../../tools/spec_workflow/artifacts.py)). Publication, push and PR writes run only in `run.py`'s process after the workflow ([autonomy.py:2261-2393](../../../tools/spec_workflow/autonomy.py)); `gh pr create --draft`, `gh pr edit --body-file -` and read-only `gh api` GETs are the whole write surface (`test_argv_never_merges_or_forces`).
- **Operator credentials.** `confined_env` drops every secret-named variable, `SSH_AUTH_SOCK`, `GPG_AGENT_INFO`, `GIT_ASKPASS`, `GH_CONFIG_DIR` and `XDG_CONFIG_HOME` except the integration's own key; `confined_argv` empties the fixed credential directories and the resolved custom locations, masks `.git-credentials`, `.netrc`, `.pypirc` and overlays the agent homes ([1279-1291](../../../tools/spec_workflow/autonomy.py), [1432-1455](../../../tools/spec_workflow/autonomy.py)). `run.py` withholds the GitHub token variables from the engine ([run.py:156-168](../../../tools/spec_workflow/run.py)). On the operator-side publish path: `git()` resolves the binary outside working trees and temp roots and passes `core.hooksPath=/dev/null`, `core.fsmonitor=false` and an override emptying every configured filter driver ([1022-1077](../../../tools/spec_workflow/autonomy.py)); the push runs from an empty-config bare repository in the operator state directory with `GIT_CONFIG_*` and Git location variables stripped, to the pinned repository's URL, never `origin` ([2429-2480](../../../tools/spec_workflow/autonomy.py)); `gh` starts in an empty temporary directory under `GIT_CEILING_DIRECTORIES` with a PATH minus checkout and temp roots ([draft_pr.py:235-279](../../../tools/spec_workflow/draft_pr.py)); the Git configuration and hooks snapshot, program/include findings and `.gitattributes` driver use are re-checked before the commit ([2323-2333](../../../tools/spec_workflow/autonomy.py)). `.git/` is read-only to agents, which removes the configuration-mutation class the snapshot also guards.
- **No provisional decision reads as human approval.** `render_record` and `render_pr_body` state that every decision is agent-provisional and merge is the only approval ([2181-2243](../../../tools/spec_workflow/autonomy.py)); `_guard_body` rejects approval wording ([2396-2399](../../../tools/spec_workflow/autonomy.py)); the intent recorder refuses an `intent.md` carrying a human approval block or digest line ([artifacts.py:1450-1460](../../../tools/spec_workflow/artifacts.py)); `renew_intent` blocks a stale intent rather than renewing it ([1505-1550](../../../tools/spec_workflow/artifacts.py)); only an `approved` verdict proceeds ([1420-1434](../../../tools/spec_workflow/artifacts.py)). DEC-0007 and DEC-0008 resolutions are labeled provisional, "confirm at merge". ADR-0004 stays `proposed` until the merge, consistent with BL-INV-006.
- **SC-007.** `git diff origin/main...HEAD -- templates/spec-kit/workflows/feature/workflow.yml` is empty (0 bytes); the workflows directory diff adds only `autonomous/` and `continue/`.
- **Fail-closed paths.** `_gh`: non-zero exit, invalid JSON and a non-object PR reply all raise; `_pr_problem` requires `draft is True` and `state == "open"`, never the absence of a flag; `run_checks` requires the frozen tree before running, blocks on any tree change, any protected-input change and any non-zero or timed-out check, and records `checked_tree` only after all three ([artifacts.py:1563-1650](../../../tools/spec_workflow/artifacts.py)); `publish` refuses when the tree differs from `checked_tree`.
