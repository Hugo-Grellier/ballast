### PD-0002 basis

> Proposal 6 of Issue #147 asks Autonomous start to offer an Issue-named branch but does not say how without a TTY. Refusing with the exact command never moves the checkout without an answer, matches ADR-0005's rule that the launcher does not change branches unasked, and adds no authority because the operator's agent session can run the printed command itself. It is a UX detail of an existing refusal and can be widened to automatic switching in a later release.

### PD-0003 basis

The narrower reading covers that #141 case while keeping ADR-0009's dead-wrapper refusal where the agent's processes are unconfirmed, so no tamper path weakens. It can be widened later without migrating any record.
